# FitCoach: วิธีติดตั้งบน iPhone (ฟรี)

แอปนี้เป็นเว็บแอป (PWA) ต้องอยู่บนเว็บแบบ HTTPS กล้องถึงจะใช้ได้ วิธีที่ง่ายและฟรีคือ GitHub Pages

## ขั้นตอน (ทำบนคอมหรือมือถือก็ได้ ~10 นาที)
1. สมัคร/ล็อกอิน https://github.com
2. กด **New repository** ตั้งชื่อเช่น `fitcoach` เลือก **Public** แล้วกด Create
3. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (index.html, app.js, data.js, anim.js, pose.js, sw.js, manifest.webmanifest และโฟลเดอร์ icons) แล้วกด Commit
4. ไปที่ **Settings › Pages** ตรง Source เลือก `Deploy from a branch` เลือก Branch: `main` / `(root)` แล้วกด Save
5. รอ 1–2 นาที จะได้ลิงก์แบบ `https://ชื่อคุณ.github.io/fitcoach/`

## ติดตั้งลง iPhone
1. เปิดลิงก์ใน **Safari**
2. กดปุ่มแชร์ (สี่เหลี่ยมลูกศรขึ้น) แล้วเลือก **เพิ่มไปยังหน้าจอโฮม**
3. เปิดจากไอคอน FitCoach บนหน้าจอโฮม (เต็มจอเหมือนแอป)
4. ครั้งแรกที่ใช้กล้อง ให้ต่อเน็ตเพื่อโหลด AI ตรวจท่า (~10MB) หลังจากนั้นใช้ออฟไลน์ได้

## เสียงภาษาไทยให้ชัดขึ้น
ตั้งค่า › การช่วยการเข้าถึง › เนื้อหาที่พูด › เสียง › ไทย แล้วดาวน์โหลด Kanya (ปรับปรุงแล้ว)

## วิธีวางกล้อง
- ท่าที่ต้องเห็นด้านข้าง (สควอท วิดพื้น แพลงก์ ลันจ์ บริดจ์ โรว์): วางมือถือด้านข้างลำตัว
- ท่าที่ต้องเห็นด้านหน้า (กระโดดตบ ดันดัมเบล): วางมือถือด้านหน้า
- ห่าง 2–3 เมตร ระดับเอว เห็นตั้งแต่หัวจรดเท้า แสงสว่างพอ

## ข้อมูล
ข้อมูลทั้งหมดเก็บในเครื่อง ถ้าลบแอปจากหน้าจอโฮมหรือล้างข้อมูล Safari ข้อมูลจะหาย ควรกด "สำรองข้อมูล" ในแท็บ "ฉัน" เดือนละครั้ง
